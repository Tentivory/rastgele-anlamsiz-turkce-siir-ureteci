# 🌌 RASTGELE ANLAMSIZ TÜRKÇE ŞİİR ÜRETECİ 🌌

## DİKKAT: BU PROJE EVRENİN EN ÖNEMLİ KEŞFİDİR

Değerli bilim insanları, filozoflar, şairler ve tesadüfen buraya düşmüş zavallı insanlar...

Bu repository, insanlık tarihinin en büyük atılımını temsil etmektedir.  
Yıllarca süren yoğun araştırma, 47 paralel evrende yapılan deneyler ve 3.5 litre Türk kahvesi tüketiminin ardından nihayet **tamamen anlamsız ama bir o kadar da derinlikli** Türkçe şiirler üreten bir yapay zeka doğmuştur.

### Neden Bu Kadar Önemli?
- Çünkü anlam aramak artık gereksizdir.
- Çünkü anlam aramamak daha da gereksizdir.
- Çünkü bu kod çalıştığında uzay-zaman dokusu hafifçe titrer.
- NASA, CERN ve Eskişehir Belediyesi bu projeyi yakından takip etmektedir (iddia ediyoruz).

### Nasıl Çalışır?
1. Python'u aç.
2. `siir_ureteci.py` dosyasını çalıştır.
3. Ekrana dökülen anlamsızlığa hayran kal.
4. Hayatını sorgula.
5. Bir daha asla sorgulama.

### Kurulum
```bash
# Hiçbir şey kurmana gerek yok. Python yeter.
python siir_ureteci.py
```
